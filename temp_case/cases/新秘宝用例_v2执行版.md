# 新秘宝（仙机）测试用例 v2 执行版

> 覆盖原《新秘宝用例.xlsx》119 条；老虎机动画未完成，动画类 11 条+关联断言转入缓测清单。

## 与原用例的关键差异（按实现静态核对）

1. **倍率体系**：原用例为“转轮图案组合决定 1~4 倍”（3³=27 组合枚举）；实现为**每次开启请求按权重随机一个倍率 {1:50%, 2:37%, 4:9%, 10:4%} 整批生效**（服务端 cfg_box_base.lua rate）。RATE-001~005 已按实现重写，差异提交策划确认（MIB-E6）。
2. **3 倍图资源已做但配置不可达**（treasurebox_img03_3beijiangli 存在，rate 无 3）——待确认。
3. **货币即“仙机”**：开启按钮文案“开启N个/暂无仙机”，5 种货币=道具 1001~1005（青纹灵钱/澜海通宝/紫霄灵币/炎煌玄币/赤霄神币）。
4. **默认档位**：持有数在 [1,5,10,50,200] 中取 ≤持有数 的最大档；不足拦截走道具获取途径弹窗，服务端兜底 1027。
5. **结算**：合计=基础单次产量×次数×倍率（客户端 DescItem 滚动展示），基础+碎片(is_conver)分列。
